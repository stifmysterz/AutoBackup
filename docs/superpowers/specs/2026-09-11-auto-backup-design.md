# Auto Backup — 设计文档

日期: 2026-09-11

## 1. 概述

一个 Windows 桌面软件，常驻系统托盘，按用户设定的时间自动把指定文件夹
（默认 Desktop、Documents，可自定义增删）增量备份到指定的外置硬盘，
保留历史版本，超过保留期的旧版本自动清理。

## 2. 技术栈

- C# / .NET 8，WinForms
- 编译为自包含单文件 `.exe`，无需安装 .NET 运行时或其他依赖，双击即可运行
- 常驻系统托盘（NotifyIcon），支持开机自启（可在设置中开关）

## 3. 模块划分

- **设置窗口**：选源文件夹、选目标硬盘、选备份计划（星期几 + 时间）、保留天数
- **硬盘识别模块**：通过 WMI 读取磁盘卷序列号（VolumeSerialNumber），配置中
  保存序列号而非盘符；每次备份前扫描当前所有磁盘，匹配序列号找到目标硬盘的
  当前盘符（应对硬盘换接口后盘符变化的情况）
- **备份引擎**：增量备份 + 版本化快照 + 自动清理（见第4节）
- **调度器**：程序内 `System.Threading.Timer`，每分钟检查是否到达设定的
  备份时间点，不依赖 Windows 任务计划程序，方便自行处理"硬盘未连接"等情况
- **通知模块**：Windows 原生通知（成功/失败/硬盘未连接提醒）
- **日志模块**：文本/JSON 日志，记录每次备份的时间、结果、文件数；日志文件
  本身有大小/天数上限，超过自动清理旧日志，避免无限增长
- **单实例保护**：程序启动时用一个命名的 Mutex 检测是否已有实例在运行，
  如果已在运行则新启动的实例直接退出（可提示"已在托盘运行"后退出）

## 4. 备份引擎（增量 + 版本化 + 自动清理）

采用类似 Time Machine / rsnapshot 的硬链接快照方案：

### 目录结构（外置硬盘上）

```
外置硬盘\AutoBackup\
  ├─ 2026-09-11_2200\   ← 某次备份的完整快照
  ├─ 2026-09-12_2200\
  └─ 2026-09-13_2200\
```

每个带时间戳的快照文件夹在逻辑上都是当时源文件夹的完整副本，但物理存储
只增加"变化过的文件"占用的空间。

### 单次备份流程

1. 找到上一次的快照文件夹（若是首次备份则没有）
2. 在临时命名的文件夹中开始构建本次快照（避免中途失败留下半成品）
3. 逐文件比较（按文件大小 + 最后修改时间）：
   - 未变化 → 在新快照中创建 NTFS 硬链接指向上一份快照中的同一文件（不占新空间）
   - 新增或有变化 → 真正复制文件
4. 源文件夹中已删除的文件，本次快照自然不会包含，但历史快照仍保留该文件
5. 全部复制完成后，逐一核对新快照中每个文件的大小是否与源文件一致
   （完整性校验），有不一致的记入日志并计入"部分完成"
6. 校验通过后，将临时文件夹原子性地重命名为正式的时间戳文件夹名；
   若中途被打断（硬盘拔出、程序退出等），临时文件夹视为无效，下次重新执行

### 启动前安全检查

- **源/目标重叠检测**：保存设置或每次备份开始前，检查备份目标硬盘（或其
  上的 `AutoBackup` 文件夹）是否落在任一源文件夹范围内，或某个源文件夹是否
  包含了目标位置，一旦检测到重叠就阻止保存/阻止本次备份，并提示用户调整
  选择，避免备份文件夹递归复制自己

### 自动清理

- 保留天数可在设置中配置（默认 30 天）
- 清理时删除超过保留天数的快照文件夹；因使用硬链接，删除某个快照只是移除
  对应的引用计数，不会影响仍被其他快照引用的实际数据
- 始终保留至少最近一份快照，即使它已超过保留天数，避免因长期未插硬盘导致
  备份被清空

### 排除规则

以下内容不会被复制进快照，也不参与文件变化比较（固定规则，MVP 阶段不做成
可配置项）：

- **隐藏/系统文件或文件夹**：Windows 标记为 Hidden 或 System 属性的（如
  `desktop.ini`），整个跳过
- **临时文件**：按名称规则匹配跳过，包括 `*.tmp`、`*.temp`、`~$*`
  （Office 编辑锁文件）、`Thumbs.db`
- **缓存文件/文件夹**：文件名或文件夹名中包含 `cache`（不区分大小写）的，
  整个跳过
- **自定义排除清单**：以上是固定规则，此外用户可在设置窗口中自行添加想
  跳过的文件夹路径或文件名模式（比如某个不想备份的大文件夹），存在配置里，
  作用范围和固定规则一样，跳过复制且不参与比较

## 5. UI 设计

### 托盘图标右键菜单

- 立即备份
- 打开设置
- 查看备份日志
- 状态提示（灰色文字，如"上次备份：今天 22:00 成功"）
- 退出

### 设置窗口

1. **备份来源**：列表框，默认勾选 Desktop、Documents，可通过"添加文件夹"
   按钮任意增加，也可删除已有项
2. **备份目标**：显示当前识别到的外置硬盘（型号/卷标 + 剩余空间）；
   "更改硬盘"按钮重新绑定硬盘（记录其卷序列号）；未连接时显示提示文字
3. **备份计划**：周一到周日复选框（勾选要备份的天）+ 时间选择器；
   "保留天数"输入框（默认30，可修改）
4. **排除清单**：文本列表框，可添加/删除自定义要跳过的文件夹路径或文件名
   模式（固定的隐藏/临时/缓存规则不在此显示，始终生效）

窗口底部有保存/取消按钮和"立即备份一次"测试按钮。关闭窗口只是最小化到
托盘，仅"退出"菜单项会真正结束程序。

## 6. 错误处理 & 通知

| 场景 | 处理方式 |
|---|---|
| 定时时刻硬盘未连接 | 跳过本次，弹通知提醒插硬盘，下一个定时点再检查 |
| 硬盘剩余空间不足 | 备份前估算数据量并与剩余空间比较，不够则跳过本次并弹通知，不自动删旧快照腾空间 |
| 单个文件复制失败（占用/权限） | 跳过该文件并记日志，继续复制其余文件，结束后弹"部分完成，X个文件跳过"通知 |
| 复制完成但完整性校验发现文件大小不一致 | 记入日志，计为"部分完成"，弹通知列出问题文件 |
| 备份中途被打断 | 依赖临时文件夹+原子重命名机制，不会留下半成品快照 |
| 设置中源/目标文件夹存在重叠 | 阻止保存设置，弹提示说明具体是哪两个路径冲突 |
| 程序启动时检测到已有实例在运行 | 新实例直接退出，不弹二次托盘图标 |
| 备份成功 | 静默更新托盘提示文字，不弹打扰性通知 |
| 备份失败/部分失败 | 弹出较明显的 Windows 通知 + 写入日志 |

## 7. 测试方式

- **单元测试**：备份引擎核心逻辑（变化判定、复制/硬链接决策、清理策略）
  独立成可测试的类，使用临时文件夹模拟源目录和目标目录，不依赖真实硬件
- **手动集成测试**：
  1. 插入真实外置硬盘，走设置流程完成绑定
  2. 手动触发一次备份，检查快照目录与文件内容
  3. 修改/删除源文件后再次备份，验证增量与硬链接行为正确
  4. 拔掉硬盘后触发定时备份，验证提醒逻辑而非崩溃
  5. 调小保留天数，验证旧快照被正确清理且未被清理的快照数据完整
